# Разработка

## Окружение

| Инструмент | Версия | Зачем |
|---|---|---|
| Go | ≥ 1.26 | Backend |
| R | ≥ 4.3 | Анализ (`Rscript` должен быть в `PATH`) |
| Node.js | ≥ 20 | Сборка фронтенда |
| make, curl, python3, ss | — | Команды Makefile |

R-пакеты ставятся в `R_LIBS_USER` (по умолчанию `~/R/lib`), прав администратора не нужно:

```bash
make install
```

## Режим разработки

```bash
make dev
```

Собирает и запускает Go-сервер на `:8080` и Vite dev-сервер на `http://localhost:5173` с горячей перезагрузкой; `/api` проксируется на `:8080`. При изменении Go-кода перезапустите команду; изменения R-скриптов подхватываются без перезапуска, но **кэш результатов** сохраняется до перезапуска сервера.

Вызвать метод R напрямую, без сервера:

```bash
echo '{"data_dir":"data/raw","locations":[{"id":"minsk","name":"Минск","zone":"","lat":53.9,"lon":27.57}],"params":{"loc":"minsk"}}' \
  | Rscript --vanilla analysis/run.R seasonality
```

## Тесты

```bash
make test
```

Запускает `go vet`, `go test ./...` (разбор и валидация ответов Open-Meteo) и `analysis/tests/test_stats.R` (статистические функции). Тесты не обращаются к сети.

Перед коммитом: `make test` и `make build` должны проходить; Go-код отформатирован `gofmt`.

## Как добавить метод анализа

1. **R.** Напишите функцию `m_<name>(req)` в `analysis/methods.R`. Она получает `req$data_dir`, `req$locations` (data.frame загруженных точек) и `req$params`, возвращает список, который сериализуется в JSON. Ряды загружайте через `get_series(req, id)` — так применяется общая предобработка.
2. Зарегистрируйте её в `handlers` в `analysis/run.R`.
3. **Go.** Добавьте метод и список допустимых параметров в `methods` в `backend/internal/api/api.go`. Новые параметры требуют валидации в `analysis()`.
4. **Frontend.** Создайте вкладку в `frontend/src/tabs/` и добавьте её в `TABS` в `App.jsx`. Данные получайте через `analysis('<name>', {...})` из `api.js`.
5. Если метод нужно прогревать перед демонстрацией — добавьте его в цель `warmup` в `Makefile`.
6. Опишите метод в [api.md](api.md) и [methodology.md](methodology.md).

## Как добавить параметр погоды

1. Добавьте имя параметра Open-Meteo в `openmeteo.Variables` (`client.go`).
2. Добавьте короткое имя в `VARS` и физический диапазон в `LIMITS` (`utils.R`).
3. Перезагрузите данные: `make fetch` (старые CSV не содержат новой колонки).
