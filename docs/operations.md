# Эксплуатация

## Флаги сервера

```bash
./bin/server -root . -addr :8080
```

| Флаг | По умолчанию | Описание |
|---|---|---|
| `-addr` | `:8080` | Адрес HTTP-сервера |
| `-root` | `..` | Корень приложения (содержит `analysis/`, `data/`, `frontend/`) |
| `-rscript` | `Rscript` | Путь к исполняемому файлу Rscript |
| `-start` | `1950-01-01` | Начало загружаемого периода |
| `-end` | `2024-12-31` | Конец загружаемого периода |
| `-static` | `<root>/frontend/dist` | Каталог собранного фронтенда; если его нет, раздаётся только `/api` |

Переменные окружения:

| Переменная | Описание |
|---|---|
| `R_LIBS_USER` | Каталог R-пакетов, передаётся в `Rscript` (Makefile ставит `~/R/lib`) |

Порт в командах Makefile меняется через `ADDR`: `make start ADDR=:9000`.

## Запуск в фоне

| Команда | Действие |
|---|---|
| `make start` | Собрать и запустить в фоне; PID — `bin/server.pid` |
| `make stop` | Остановить |
| `make logs` | Следить за логом `bin/server.log` |
| `make warmup` | Прогреть кэш всех вкладок |
| `make demo` | `start` + `check` + `warmup` + открыть браузер |

## Docker

Образ многоэтапный: Node собирает фронтенд, Go — сервер, финальный слой на `r-base` содержит R с `jsonlite`.

```bash
docker build -t meteo-analytics .
docker run --rm -p 8080:8080 -v "$PWD/data/raw:/app/data/raw" meteo-analytics
```

`data/raw` не копируется в образ, а объявлен томом: без монтирования контейнер стартует без данных, и их придётся загрузить через `POST /api/fetch`.

## Логи

Сервер пишет в stdout по строке на запрос: метод, путь, длительность. Ошибки загрузки и R-скриптов логируются с префиксами `fetch <id>:` и `analysis <method>:`.

```
2026/11/24 12:00:01 GET /api/analysis/trends?loc=minsk&var=tmean 1.204s
```

## Типичные проблемы

| Симптом | Причина и решение |
|---|---|
| `Порт 8080 занят другим процессом` | Освободите порт или `make start ADDR=:9000` |
| `фронтенд не собран … раздаются только /api` | Выполните `make build-web` |
| `412 данные не загружены` | Нет CSV в `data/raw`: `make fetch-missing` или `make restore-data` |
| `500 R: … there is no package called 'jsonlite'` | `make install`; проверьте `R_LIBS_USER` |
| `500 R: превышено время выполнения` | Метод работал дольше 120 с — проверьте нагрузку и объём данных |
| Загрузка завершилась с `open-meteo: HTTP 429` | Превышен лимит API: подождите несколько минут, затем `make fetch-missing` |
| После правки R-кода результат не изменился | Сработал кэш: перезапустите сервер (`make stop && make start`) |
