# Методика

Все расчёты реализованы в [`analysis/`](../analysis/) на базовом R без сторонних статистических пакетов.

## Предобработка

Выполняется при каждой загрузке ряда (`load_series` в `utils.R`), исходные CSV не изменяются.

1. **Физические фильтры.** Значения вне допустимых диапазонов заменяются пропуском:

   | Параметр | Диапазон |
   |---|---|
   | Температура (tmax, tmin, tmean) | −90 … 60 °C |
   | Осадки | 0 … 2000 мм |
   | Ветер | 0 … 120 м/с |
   | Влажность, облачность | 0 … 100 % |
   | Давление | 850 … 1090 гПа |

2. **Интерполяция.** Пропуски длиной ≤ 3 суток, окружённые данными, заполняются линейно. Осадки не интерполируются: у суммы осадков нет гладкой динамики.
3. **Полнота агрегатов.** Годовое (сезонное) значение считается, только если заполнено ≥ 90 % (для сезонов ≥ 85 %) суток; иначе — пропуск.
4. **Сезоны.** Метеорологические: DJF, MAM, JJA, SON. Декабрь относится к зиме *следующего* года.

## Базовый период

Нормы и пороги экстремумов считаются за **1991–2020** (стандартный климатический период ВМО). Аномалия = значение − норма; для осадков — в процентах от нормы.

## Режим и сезонность

- Месячные нормы tmean, tmax, tmin, ветра, влажности — средние за базовый период.
- Месячная норма осадков — среднее месячных сумм.
- Суточная амплитуда (DTR) = tmax − tmin, усреднённая по месяцу.
- Годовые аномалии температуры и осадков за весь период.

## Сравнение регионов

1. Для каждой точки считаются показатели за базовый период: средняя температура, годовая амплитуда (разница самого тёплого и самого холодного месяца), годовая сумма осадков, средний ветер, влажность, число дней с Tmax ≥ 30 °C, Tmin < 0 °C, осадками ≥ 20 мм в год.
2. Восемь показателей стандартизуются (z-оценки).
3. **k-means** (`nstart = 50`, `seed = 42`), k задаёт пользователь (2–8, не больше числа точек − 1).
4. **PCA** — первые две компоненты используются как координаты карты сходства.

## Тренды

Годовой ряд строится агрегатом суточных значений: среднее для температуры и ветра, сумма для осадков. Применяются три независимые оценки:

| Метод | Что даёт | Комментарий |
|---|---|---|
| Тест Манна–Кендалла | τ, Z, p-value | Непараметрический, устойчив к выбросам; дисперсия S с поправкой на совпадающие значения |
| Наклон Тейла–Сена | Наклон и 95% ДИ | Медиана попарных наклонов; ДИ по Hirsch et al. (1982) |
| Линейная регрессия (МНК) | Наклон, 95% ДИ, p, R² | Для сравнения с параметрическим подходом |

- Тренд считается значимым при p < 0,05 по Манну–Кендаллу.
- Скорости приводятся к единицам **за десятилетие**.
- Требуется минимум 8 непустых лет, иначе результат — `null`.
- Тренды считаются по годам и отдельно по каждому сезону; без указания точки — рейтинг всех точек по наклону Тейла–Сена.

Автокорреляция ряда не учитывается (без предварительного «отбеливания»), поэтому значимость для рядов с сильной автокорреляцией может быть завышена.

## Экстремумы

| Показатель | Определение |
|---|---|
| Жаркий день | Tmax > P95 Tmax за базовый период |
| Волна жары | ≥ 3 жарких дня подряд (считаются серии в пределах календарного года) |
| Морозный день | Tmin < 0 °C |
| Сильный ливень | Осадки ≥ P95 осадков дождливых (≥ 1 мм) дней базового периода |
| Сухой период | Наибольшая серия суток с осадками < 1 мм в году |

Для годовых счётчиков считаются тренды (Манн–Кендалл + Тейл–Сен). Рекорды — абсолютные максимумы/минимумы за весь период с датой.

## Связи параметров

Матрицы корреляции Пирсона (линейная связь) и Спирмена (монотонная связь) для температуры, осадков, влажности, ветра, давления и облачности по суточным данным, попарное исключение пропусков. Для диаграмм рассеяния — случайная выборка 900 суток (`seed = 1`).

Корреляции по суточным данным включают сезонный ход: сильная связь может отражать общий годовой цикл, а не прямую физическую зависимость.

## Прикладные индексы

Помесячная доля суток (%) за базовый период, удовлетворяющих условию:

| Индекс | Условие |
|---|---|
| Риск для работ на открытом воздухе | Tmax ≥ 32 °C **или** Tmin ≤ −15 °C **или** осадки ≥ 10 мм **или** ветер ≥ 15 м/с |
| Комфорт для туризма | 15 ≤ Tmean ≤ 27 °C **и** осадки < 1 мм **и** ветер < 10 м/с |
| Пригодность для строительства | Tmin > 0 °C **и** осадки < 5 мм **и** ветер < 12 м/с |
| Ветровой потенциал | Среднее v³ по суточным максимумам ветра (относительный индекс, не мощность) |

Пороги — эвристики, выбранные для иллюстрации; они не соответствуют конкретным отраслевым нормативам и не заменяют официальную метеорологическую экспертизу.

## Проверка корректности

`analysis/tests/test_stats.R` проверяет на синтетических данных:

- восстановление известного наклона (0,3 за десятилетие) методами Тейла–Сена и МНК, попадание истины в 95% ДИ;
- совпадение τ Кендалла и p-value с `cor.test(method = "kendall")`;
- долю ложных срабатываний на белом шуме ≈ 5 %;
- отказ от теста при n < 8;
- интерполяцию коротких и сохранение длинных пропусков.

## Ограничения

- ERA5 — реанализ, а не наблюдения станций. Сетка ~0,25° (~25 км) сглаживает локальные экстремумы, особенно в горах (Ла-Пас) и на побережьях.
- Скорость ветра — суточный максимум на высоте 10 м, а не средняя скорость.
- Однородность ряда ERA5 до спутниковой эры (до ~1979) ниже, что может влиять на тренды за весь период.
- Тренд в отдельной точке не равен глобальному или региональному тренду.
