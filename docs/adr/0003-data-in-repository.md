# 0003. Данные в репозитории

- **Статус:** Принято
- **Дата:** 2026-10-24

## Контекст

Бесплатный Open-Meteo API ограничивает число запросов; полная загрузка 10 точек иногда завершается ошибкой 429. Приложение нужно надёжно запускать на защите и на чужих машинах, в том числе без интернета.

## Решение

Закоммитить загруженные CSV (`data/raw/*.csv`, ~15 МБ) в репозиторий. Загрузка из API остаётся для обновления данных (`make fetch`, `make fetch-missing`).

## Последствия

- `git clone` + `make install` + `make demo` работают без сети к Open-Meteo.
- Результаты воспроизводимы: все работают с одной и той же версией данных.
- Репозиторий тяжелее; при каждом обновлении данных в истории git остаётся новая копия файлов.
- Нужно соблюдать лицензию CC BY 4.0: атрибуция указана в README.

## Рассмотренные альтернативы

- **Загружать при первом запуске** — зависит от сети и лимитов API.
- **Git LFS** — лишняя настройка для объёма в 15 МБ.
