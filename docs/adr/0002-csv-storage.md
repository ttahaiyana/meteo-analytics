# 0002. Хранение рядов в CSV

- **Статус:** Принято
- **Дата:** 2026-10-24

## Контекст

Объём данных — 10 точек × ~27 тыс. суток × 8 параметров (~15 МБ). Данные только добавляются целиком при загрузке и читаются для анализа; конкурентных записей нет.

## Решение

Хранить по одному CSV на точку в `data/raw/`. Запись атомарная: во временный файл, затем `rename`. Сырые данные не изменяются — вся очистка выполняется при чтении в R.

## Последствия

- Нет СУБД для установки и администрирования; данные читаются любым инструментом.
- Сырые и обработанные данные разделены: правила очистки можно менять без перезагрузки.
- Каждый запрос анализа перечитывает CSV целиком; при росте числа точек на порядки понадобится колоночный формат (Parquet) или БД.

## Рассмотренные альтернативы

- **SQLite / PostgreSQL** — избыточны для объёма и характера нагрузки.
- **Parquet** — быстрее, но требует дополнительных пакетов в Go и R.
