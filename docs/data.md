# Данные

## Источник

[Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api) (`https://archive-api.open-meteo.com/v1/archive`), реанализ ERA5 (Copernicus Climate Change Service / ECMWF). Лицензия CC BY 4.0.

Параметры запроса: период `1950-01-01` — `2024-12-31`, часовой пояс GMT, скорость ветра в м/с.

## Формат CSV

Файл `data/raw/<id>.csv`: одна строка на сутки, 27 394 строки на точку (75 лет), ~1,5 МБ. Пустая ячейка = пропуск.

| Колонка | Короткое имя в R | Единицы | Описание |
|---|---|---|---|
| `date` | — | `YYYY-MM-DD` | Дата (GMT) |
| `temperature_2m_max` | `tmax` | °C | Максимальная температура на 2 м |
| `temperature_2m_min` | `tmin` | °C | Минимальная температура на 2 м |
| `temperature_2m_mean` | `tmean` | °C | Средняя температура на 2 м |
| `precipitation_sum` | `precip` | мм | Сумма осадков |
| `wind_speed_10m_max` | `wind` | м/с | Максимальная скорость ветра на 10 м |
| `relative_humidity_2m_mean` | `hum` | % | Средняя относительная влажность |
| `pressure_msl_mean` | `pres` | гПа | Среднее давление на уровне моря |
| `cloud_cover_mean` | `cloud` | % | Средняя облачность |

Порядок колонок задаётся `openmeteo.Variables` в [`backend/internal/openmeteo/client.go`](../backend/internal/openmeteo/client.go), соответствие коротким именам — `VARS` в [`analysis/utils.R`](../analysis/utils.R).

## Обновление данных

Сервер должен быть запущен (`make start`).

| Команда | Действие |
|---|---|
| `make fetch` | Перезагрузить все точки |
| `make fetch-missing` | Загрузить только точки без CSV |
| `make status` | Ход загрузки |
| `make check` | Проверить, что все точки на месте (код выхода 1, если нет) |
| `make backup-data` / `make restore-data` | Копия `data/raw` в `backup/raw` и обратно |

Полная загрузка занимает 1–3 минуты. Бесплатный API ограничивает число запросов: при ошибке `HTTP 429` подождите несколько минут и выполните `make fetch-missing`.

После обновления файлов кэш результатов инвалидируется автоматически (ключ кэша включает время изменения файлов).

## Добавление точки

1. Добавьте запись в `data/locations.json` (`id` — латиница, используется как имя файла).
2. Перезапустите сервер: справочник читается при старте.
3. Выполните `make fetch-missing`.

Методы `compare` и `insights` подхватят новую точку автоматически. Для k-means нужно не меньше 3 точек.
