# Аналитика погоды по данным Open-Meteo

Веб-приложение для анализа суточных метеорядов (реанализ ERA5, 1950–2024) по ~10 точкам из разных климатических зон.
Реализует тематику проекта: режим и сезонность, сравнение регионов, тренды, экстремумы, связи параметров, прикладные выводы.

## Архитектура
- **Go** (`backend/`) — HTTP API, загрузка из Open-Meteo (проверка структуры ответа, ретраи при 429/5xx), хранение сырых CSV в `data/raw/`, запуск R, кэш результатов, раздача фронтенда.
- **R** (`analysis/`) — вся статистика. Go запускает `Rscript analysis/run.R <метод>`, передаёт JSON через stdin, читает JSON из stdout.
- **React + Vite + Plotly** (`frontend/`) — дашборды (7 вкладок).

## Быстрый старт (данные уже в репозитории)
Нужны Go, R и Node.js.
```
git clone https://github.com/ttahaiyana/meteo-analytics && cd meteo-analytics
make install   # jsonlite + npm install
make demo      # сборка, запуск, прогрев кэша, открытие http://localhost:8080
```
Остановить сервер: `make stop`. Остальные команды: `make help`.

Готовые ряды 10 точек за 1950–2024 лежат в `data/raw/`, загружать ничего не нужно.

## Обновление данных
`make fetch` перекачивает все точки, `make fetch-missing` — только недостающие. Бесплатный API Open-Meteo ограничивает число запросов: при ошибке 429 подождите и выполните `make fetch-missing`.
Для разработки фронтенда: `cd frontend && npm run dev` (прокси на :8080).

## Методика
- **Предобработка:** значения вне физических диапазонов → пропуск; пропуски ≤3 суток линейно интерполируются (осадки — нет); год с долей пропусков >10% не агрегируется.
- **Норма:** 1991–2020; аномалии — отклонение от нормы.
- **Тренды:** тест Манна–Кендалла (с поправкой на совпадения), наклон Тейла–Сена с 95% ДИ, линейная регрессия; по годам и по сезонам (зима = дек–фев с декабрём предыдущего года). Скорость — на десятилетие.
- **Экстремумы:** жаркий день — Tmax выше P95 базового периода; волна жары — ≥3 таких дня подряд; ливень — осадки выше P95 дождливых дней (≥1 мм); сухой период — подряд суток с осадками <1 мм.
- **Сравнение:** унифицированные показатели → стандартизация → k-means (k выбирает пользователь) и PCA для карты сходства.
- **Прикладные индексы** (риск работ, комфорт туризма, пригодность для строительства, ветровой индекс) — эвристики с порогами, указанными в интерфейсе; не заменяют официальную метеорологическую экспертизу.

## Ограничения
ERA5 — реанализ, а не наблюдения станций; сетка ~25 км сглаживает локальные экстремумы. Скорость ветра — суточный максимум на 10 м. Тренды по отдельной точке не равны глобальному тренду.
