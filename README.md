# meteo-analytics

Веб-приложение для анализа суточных метеорядов по данным реанализа ERA5 (Open-Meteo, 1950–2024) для 10 точек из разных климатических зон: сезонность, сравнение регионов, тренды, экстремумы, корреляции параметров и прикладные индексы.

**Стек:** Go 1.26 (HTTP API) · R 4.x (статистика) · React 18 + Vite + Plotly (интерфейс)

## Быстрый старт

Нужны Go ≥ 1.26, R ≥ 4.3, Node.js ≥ 20, `make`, `curl`, `python3`.

```bash
git clone https://github.com/ttahaiyana/meteo-analytics && cd meteo-analytics
make install   # R-пакет jsonlite + npm-зависимости
make demo      # сборка, запуск в фоне, прогрев кэша, открытие http://localhost:8080
make stop      # остановить сервер
```

Данные всех 10 точек уже лежат в `data/raw/`, загружать ничего не нужно. Список всех команд: `make help`.

Запуск в Docker — см. [docs/operations.md](docs/operations.md#docker).

## Возможности

| Вкладка | Что показывает |
|---|---|
| Режим и сезонность | Месячные нормы 1991–2020, суточная амплитуда, годовые аномалии температуры и осадков |
| Сравнение регионов | Сводная таблица показателей, кластеризация k-means, карта сходства (PCA) |
| Тренды | Манн–Кендалл, наклон Тейла–Сена с 95% ДИ, МНК; по годам и сезонам; рейтинг точек |
| Экстремумы | Жаркие дни, волны жары, ливни, сухие периоды, рекорды и их тренды |
| Связи параметров | Матрицы корреляций Пирсона и Спирмена, диаграммы рассеяния |
| Прикладные выводы | Индексы риска работ, комфорта для туризма, пригодности для строительства, ветрового потенциала |

## Ограничения

ERA5 — реанализ (модель + усвоение наблюдений), а не данные метеостанций; сетка ~25 км сглаживает локальные экстремумы. Прикладные индексы — эвристики, не заменяющие метеорологическую экспертизу. Подробнее: [docs/methodology.md](docs/methodology.md#ограничения).

## Данные и лицензия

Данные: [Open-Meteo](https://open-meteo.com/) Historical Weather API (реанализ ERA5, Copernicus Climate Change Service / ECMWF), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Проект учебный, для некоммерческого использования.
