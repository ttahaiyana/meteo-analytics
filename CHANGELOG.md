## [1.0.0] — 2026-10-24

### Добавлено
- Веб-приложение анализа погоды: Go-сервер, R-анализ, React-интерфейс с 6 вкладками.
- Загрузка данных из Open-Meteo с проверкой ответа и ретраями при 429/5xx.
- Данные 10 точек за 1950–2024 в репозитории — запуск без загрузки.
- Команды Makefile для демонстрации: `demo`, `check`, `warmup`, `fetch-missing`, `backup-data`, `restore-data`.

### Удалено
- Вкладка «Качество данных» из интерфейса (метод `quality` в API сохранён).
- Кнопка «Догрузить» и счётчик точек в шапке.
